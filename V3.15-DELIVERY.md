# Companion v3.15 — Photos routing and artwork previews

This server support accompanies mobile 3.15 (16). It adds authenticated normal-Photos album browsing/creation and original-image uploads with per-file idempotent receipts, read-only/library/feature checks and mapped-directory/symlink safeguards. The native API uses `/api/photos/native`, `/albums` and `/albums/:albumID/media`. Each file is bounded to 32 MB. Very large album listings report when capped at 5,000 photos.

The scanner stops borrowing the normal Photos mapping for Adult Photos. The account-filtered media-index response also excludes stale Adult Photos entries demonstrably sourced from the implicit normal-Photos alias, while respecting explicit Adult Photos mappings. Files are not moved or deleted; rescan Photos and Adult Photos after installation.

Authorized `/api/file` image previews now actually resize local JPG/PNG/WebP/GIF/AVIF artwork, preserve orientation and use a bounded-concurrency cache keyed by source path/size/mtime and output settings. Full originals and the existing HEIC path remain available. Preview processing does not inspect nudity/content. No server transcoding changes are included.
