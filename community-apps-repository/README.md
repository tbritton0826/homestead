# Homestead Community Apps repository

This small public repository contains the Unraid Community Apps metadata for
Homestead. It does not contain the Homestead application source.

## Publish this repository

1. Create a public GitHub repository named `homestead-community-apps` under
   `tbritton0826`.
2. Copy the contents of this folder to the repository root.
3. Confirm that the raw `TemplateURL` and icon URLs load without signing in.
4. Publish `ghcr.io/tbritton0826/homestead:latest`, then change the GHCR
   package visibility to **Public** before submitting the listing.
5. Submit the repository URL at https://ca.unraid.net/submit and run Validate,
   then Scan.

The MIT license in this folder applies only to this template repository and its
metadata. It does not grant rights to the Homestead application or container
image.
